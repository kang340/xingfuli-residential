# 幸福里 · 3号楼 —— 中国居民楼三维场景

**简体中文** | [English](README.en.md)

**使用 DeepSeek V4.1 Flash 1017 制作。**

[网页预览](https://kang340.github.io/xingfuli-residential/) · [GitHub](https://github.com/kang340/xingfuli-residential) · [MIT 许可](LICENSE)

网页支持中英文切换、五个机位浏览和大图查看，展示 Blender 渲染图；完整三维工程可下载后用 Blender 打开。

一个完全由 Python 程序化生成的 Blender 场景：六层砖混住宅、底层沿街商铺、三个单元入口、封阳台与开放式阳台、屋顶太阳能与水箱，以及一条有梧桐、汽车、自行车、行人、猫和架空电线的老街。

场景约 **5,900 个对象**（其中 5,600+ 个网格、110+ 条曲线/文字），主工程约 4.6 MB。

场景没有使用任何外部图片贴图，墙面砖缝、水泥、沥青、树叶、布料、锈迹都由程序化材质完成。

## 一、快速开始

### 直接打开

用 **Blender 5.2 LTS 或更高版本**打开：

```
中国居民楼_幸福里.blend
```

打开后按 `F12` 即可渲染当前主视角。场景中已保存五个机位，可在右侧「相机」数据块中切换：

| 相机 | 内容 | 建议用途 |
| --- | --- | --- |
| `相机_主视角` | 整栋楼 + 街道全景 | 主图 / 封面 |
| `相机_立面细节` | 中低层立面、阳台、商铺招牌 | 立面细节 |
| `相机_单元入口` | 2 单元门头、雨棚、信箱、横幅 | 入口细节 |
| `相机_街景` | 沿街视角，树、车、行人 | 街道氛围 |
| `相机_屋顶` | 屋顶太阳能、水箱、天线 | 屋顶细节 |

### 重新生成场景

在仓库根目录运行以下命令（请将 Blender 安装路径换成自己的路径）。重新生成会覆盖工程，请先备份手工修改：

```powershell
& "D:\Blender Foundation\Blender 5.2\blender.exe" `
  -b --factory-startup `
  --python ".\scripts\build_scene.py"
```

加 `-- --preview` 会额外渲染一张 960×540 的快速预览：

```powershell
& "D:\Blender Foundation\Blender 5.2\blender.exe" `
  -b --factory-startup `
  --python ".\scripts\build_scene.py" -- --preview
```

### 重新渲染成品图

```powershell
& "D:\Blender Foundation\Blender 5.2\blender.exe" `
  -b --factory-startup `
  --python ".\scripts\render_final.py"
```

成品输出到 `renders/`。

## 二、场景内容

### 建筑

- 面宽 **36 m**，进深 **12 m**，屋面高度 **22.05 m**。
- 底层为商业 + 门厅，层高 4.35 m；上部 6 层住宅，标准层高 2.95 m。
- 9 个 3.9 m 开间：3 个楼梯间（0、4、8 轴），6 个住宅开间。
- 三个单元入口：`1 单元`（西）、`2 单元`（中）、`3 单元`（东），中间单元更宽。
- 外墙为暖米色小方砖 + 浅色涂料腰线 + 深色勒脚，砖缝按世界坐标对齐，不会随物体缩放拉伸。
- 立面细节：封阳台 / 开放阳台、防盗网、空调外机与冷媒管、雨水管、燃气立管、晾衣杆与衣物、花盆、拖把、雨棚、单元号牌、信报箱、电表箱、可视对讲、门灯、社区横幅、灯笼。
- 屋顶：楼梯出屋面、太阳能热水器阵列、不锈钢水箱、电视天线、卫星锅、通气管、屋顶晾衣绳、鸽笼、屋面补丁和散落砖块。

### 底层商铺

| 店铺 | 位置（x） | 内容 |
| --- | --- | --- |
| 老陈烟酒 | -13.9 … -8.9 | 烟酒副食、玻璃柜台、货架、冰柜、成箱饮料、门口塑料凳 |
| 阿香理发 | -8.6 … -3.6 | 镜台、理发椅、洗发池、转灯、毛巾、价目牌 |
| 兰州牛肉面 | 2.3 … 7.3 | 后厨窗口、面案、碗筷、红灯笼、门口折叠桌与塑料凳、蒸汽 |
| 老周修车 | 7.6 … 12.6 | 工作台、工具板、轮胎、配钥匙机、打气筒、立轮 |

招牌均为真实文字网格（不是贴图），使用系统中文字体；夜间/黄昏时店内暖光会从玻璃门透出。

### 街道

- 人行道方砖、路缘石、排水篦子、井盖、积水、落叶。
- 沥青路面、车位线、减速带、道路标线。
- 两棵主梧桐、两棵稍远梧桐、四棵背景树，单棵约 4,700–6,700 片叶子；树池、支撑架、涂白树干。
- 电线杆、架空线、路灯、配电箱、旧电话亭、院墙与院门。
- 一辆白色桑塔纳风格轿车、一辆银色面包车、一辆三轮车、多辆自行车与电动车。
- 长椅、垃圾桶、分类垃圾亭、纸箱、旧家具、晾晒的拖把。
- 人物：买菜的阿姨、坐在路边的老人、修车师傅；还有一只流浪猫。
- 左右邻楼与远景住宅楼，形成完整的街区关系。

### 光照与色彩

- 低角度黄昏太阳（仰角约 18°），暖色主光 + 冷色天空补光 + 地面反弹光。
- 天空使用多重散射 Sky Texture；世界无体积雾，避免画面发灰。
- AgX 视图变换，`AgX - Medium High Contrast`，曝光 +0.02。
- 合成器仅做很轻的 Fog Glow 与暖高光/冷暗部分离，不改变建筑固有色。

## 三、工程结构

```
3d居民楼/
├─ 中国居民楼_幸福里.blend      # 主工程
├─ README.md
├─ renders/
│  ├─ 00_预览总览.jpg
│  ├─ 01_主视角.png
│  ├─ 02_立面细节.png
│  ├─ 03_单元入口.png
│  ├─ 04_街景.png
│  └─ 05_屋顶.png
└─ scripts/
   ├─ scene_lib.py              # 通用建模/材质/曲线/文字工具
   ├─ parts_building.py         # 建筑主体、立面、阳台、屋顶
   ├─ parts_ground.py           # 底层商铺、入口、基座
   ├─ parts_street.py           # 街道、植物、车辆、人物、邻楼
   ├─ build_scene.py            # 总装、灯光、相机、保存
   └─ render_final.py           # 成品渲染
```

### 关键约定

- 单位：米；Z 轴向上。
- 建筑正立面在 `y = -6`，街道朝 `-Y` 方向展开。
- 建筑中心线 `x = 0`，面宽范围 `x = -18 … +18`。
- 字体在 `scene_lib.load_fonts()` 中加载；默认优先使用 `NotoSansSC-VF.ttf` / `NotoSerifSC-VF.ttf`，找不到时回退到 Windows 的 `msyhbd.ttc`。
- 随机种子固定，重复生成结果一致：
  - 建筑 `7319`
  - 底层 `8417`
  - 街道 `6912`

## 四、渲染设置

| 项目 | 主图 | 细节图 |
| --- | --- | --- |
| 分辨率 | 1600 × 900 | 1280 × 720 |
| 采样 | 64 | 48 |
| 引擎 | Cycles GPU（OptiX） | 同左 |
| 降噪 | OptiX Denoise | 同左 |
| 视图变换 | AgX / Medium High Contrast | 同左 |

如果显卡显存较小，可以把 `render_final.py` 中的分辨率或采样调低；场景在 960×540、48 采样下约 6–10 秒可出图。当前成品图使用 64/48 采样并开启降噪，兼顾细节与出图时间；需要更大尺寸时，直接改 `render_final.py` 中的分辨率与采样即可，渲染时间会相应增加。

### 常见调整

- **想更暖/更冷**：改 `build_scene.py` 中 `夕阳` 的颜色与 `世界` 的 Background 强度。
- **想更暗的黄昏**：降低 `scene.view_settings.exposure`（当前 `0.02`），或降低太阳能量 `6.4`。
- **树太密/太疏**：`parts_street.py` 中 `_make_tree()` 的 `count` 与 `rad` 范围。
- **招牌文字被挡**：调整对应店铺的 `x0/x1` 或招牌高度；文字对象名以 `招牌字_` 开头。
- **渲染太慢**：把 `sc.cycles.samples` 再降到 32–48，或关闭 `use_persistent_data`。

## 五、说明与限制

- 所有模型、材质、文字均为程序化生成，没有外部模型或贴图；因此 `.blend` 体积小，但打开后首次渲染需要编译着色器。
- 场景按“中国普通城市老小区”设计，不追求某一栋真实建筑的测绘还原。
- 文字使用系统中文字体；如果换到没有这些字体的机器，Blender 会提示字体丢失，可在 `scene_lib.py` 的 `load_fonts()` 中改成目标机器上的中文字体路径。
- 屋顶设备、商铺内景、阳台杂物均为示意性细节，近景细看会有简化。
